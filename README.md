# Personal skills

手动安装技能的 Git 快照和维护仓库。包含 14 个独立技能与本地 Superpowers 技能集合。

## 目录

- `skills/`：独立技能的完整安装内容，保留原目录名与内部结构。
- `vendor/superpowers/skills/`：Superpowers 技能集合，附带上游许可证。
- `skills-lock.json`：来源、已知上游 commit、安装位置和首次迁移的 SHA-256 文件清单。

不包含插件、系统 `.system` 技能、嵌套 Git 数据库和缓存文件。来源未知的技能按当前本地快照保存，不推测上游版本。各第三方目录保留其原有许可证；本仓库不统一更改许可。

## 当前安装

本机原安装路径使用符号链接指向本仓库。直接编辑本仓库中的技能文件后，通过 Git 提交和推送。迁移备份保存在仓库之外，嵌套 Git 历史保留在原始目录备份中。

## 在其他电脑上恢复

克隆本仓库后，将每个 `skills/<目录名>` 链接到 `~/.agents/skills/<目录名>`，将 `vendor/superpowers/skills` 链接到 `~/.agents/skills/superpowers`。先检查已有安装，避免覆盖或重复加载。

## 更新

更新第三方技能前先检查工作区，使用固定上游版本，对照本地修改审阅差异，再提交。`skills-lock.json` 的文件哈希记录首次迁移基线；后续修改历史以 Git 为准。新增来源或升级上游版本时同步更新来源记录。
